# Barlas Print Studio mobile app

Initial Expo / React Native prototype for iOS and Android. This is a **development prototype**, not a published or production-ready shop.

## Run

Install Node.js, then from this directory run:

```bash
npm install
npx expo start
```

Use Expo Go for early preview. Native builds and store submissions require additional configuration and testing.
